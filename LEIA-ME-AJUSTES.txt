============================================================
NOVO — SISTEMA DE INSCRIÇÕES / INGRESSOS
============================================================

1. CPF obrigatório no Checkout Blocks, com validação matemática.
2. CPF salvo no pedido pelo sistema oficial de Additional Checkout Fields do WooCommerce.
3. Quando o pagamento é confirmado, o pedido recebe um código único no formato BC26-XXXX-XXXX.
4. O cliente recebe no e-mail um botão “Visualizar meu ingresso”.
5. A página /consultar-inscricao/ permite consultar por CPF + e-mail.
6. O ingresso mostra CPF e e-mail mascarados.
7. O ingresso possui QR Code para /validar-ingresso/, assinado para evitar adulteração simples.
8. A página de validação mostra apenas dados mínimos e o status atual do pedido.
9. As páginas “Consultar inscrição” e “Validar ingresso” são criadas automaticamente ao acessar o painel do WordPress como administrador.
10. Pedidos PIX pendentes não recebem ingresso válido até o WooCommerce confirmar o pagamento.

OBSERVAÇÃO SOBRE QR CODE:
O desenho do QR Code é carregado pela API pública api.qrserver.com. O conteúdo enviado à API é somente a URL assinada de validação do ingresso; CPF, nome e e-mail não são enviados para esse serviço.

SEGURANÇA:
A consulta pública não usa CPF sozinho. É obrigatório informar CPF + e-mail. O link enviado por e-mail usa código do ingresso + chave privada do pedido WooCommerce.
